Step 3

Feature Engineering (Econometric & Statistical Feature Store)

Raw data streams are transformed into analytical inputs. Econometric features (e.g. trend slopes, account resilience, and ADF stationarity tests on transaction series) are combined with statistical features (e.g., average billing delays and geolocation consistency metrics) to produce the model feature vector.

Step 5

Explainable Boosting Machine (EBM) Scorecard

The core champion model is a glass-box Explainable Boosting Machine. It calculates predictions additively. Each feature's shape function defines a score contribution in log-odds. The log-odds are translated directly into credit score points, allowing exact tracing of how the final score is reached.

Step 6

Conformal Prediction & Multi-Model Panel Audit

To avoid false trust, the system executes two challenger models (CatBoost and Logistic Regression) alongside the EBM champion. A conformal prediction gate evaluates uncertainty. If the challengers disagree with the champion, or the conformal prediction set contains high variance, the decision is routed to manual review.

Step 7

Affordability Gate & Lending Overlay

After model classification, a financial guardrail evaluates the applicant's request. It checks if the requested loan amount exceeds the EBM-approved maximum limit, which is calculated based on cashflow capacity. If there is a funding gap, the decision shifts to Review for a counter-offer.

Translation to Bank LOS Dashboard Components
